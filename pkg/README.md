# litmus-accounting

Pure accounting engine for crypto and trading books. Import `litmus.accounting`
to turn dated ledger events into lots, cost basis, realized profit and loss, and
an exceptions report. The package also provides the `accounting` command.

It needs no database or network connection. Callers provide prices and policy.
Python 3.11 or newer is required. Licensed under the MIT license.

See the repository documentation for the ledger model, CLI and examples:
https://github.com/litmus-tax/accounting
